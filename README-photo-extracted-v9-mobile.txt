Photo-extracted Guitar Chord Flashcards — v9 mobile layout

Mobile/iOS layout improvements:
- Practice card is now the first section on phones.
- Sticky compact header with safe-area support.
- Fretboard is centered and scaled for iPhone width.
- Chord title and metadata are tightened to reduce wasted vertical space.
- Prev / next / half-step controls use a 2-column mobile grid.
- Note Names / Finger Numbers / Chord Degrees stay side-by-side as compact tabs.
- Chord-group and root toggles use a 2-column layout on most phones.
- On very narrow phones, toggle lists collapse to one column.
- Larger touch targets throughout.
- Fret-range fields are easier to use with the iOS numeric keyboard.
- Shape list remains below the practice controls rather than crowding the fretboard.

Functionality and chord data are unchanged from v8.
